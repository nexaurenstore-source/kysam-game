# Sistema de Combate — Kysam Game

## Fundação

O combate é separado dos modelos e animações para permitir que cada personagem tenha identidade própria.

Cada Combatant poderá ter:

- atributos próprios;
- ataques básicos;
- defesa;
- esquiva;
- combos;
- arma especial;
- poder único;
- ultimate no futuro.

## Fase inicial

A primeira implementação técnica cobre:

- ataque leve;
- ataque especial baseado em energia;
- defesa com redução de dano;
- vida;
- energia;
- derrota;
- estados READY, FIGHTING, VICTORY e DEFEAT.

## Próximas extensões

1. Hitbox e hurtbox reais.
2. Distância obrigatória para ataques.
3. Animações de ataque.
4. Knockback.
5. Esquiva com invulnerabilidade curta.
6. Combo.
7. IA do adversário.
8. Poder único por personagem.
9. Arma especial por personagem.
